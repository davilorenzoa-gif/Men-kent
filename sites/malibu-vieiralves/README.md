# Malibu Vieiralves (lead do Davi)

Hamburgueria em Manaus. Rua Rio Javari, 43, Nossa Senhora das Graças (Vieiralves). WhatsApp (92) 99213-6850.
4,7 no Google com 577 avaliações (via Wanderlog, conferir no Maps). Terça a domingo, 17h45 às 00h.

- `index.html` + `img/`: versão pra subir no Netlify (`proposta-malibu` → `malibu-vieiralves`).
- `preview-malibu.html`: o mesmo site com as imagens embutidas, pra abrir direto no celular.
- `404.html`, `privacidade.html`, `robots.txt`, `sitemap.xml`.

3 WOWs:
1. Abertura: o burger (vídeo feito no Google Flow, 96 quadros em `img/burger/`) sobe e desmonta camada por camada com a rolagem, com o nome de cada camada; depois monta de volta. Marcado como "imagem ilustrativa".
2. Rota pela costa: os burgers têm nome de praia da Califórnia (Malibu, Santa Mônica, Long Beach, Oceanside); um carrinho desce o mapa e para em cada um.
3. Prancha de pedido: cada item escolhido vira um adesivo colado na prancha de surf; o pedido vai pronto pro WhatsApp.
