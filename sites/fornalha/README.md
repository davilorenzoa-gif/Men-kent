# Fornalha Padaria (demo GuDev)

Padaria **fictícia**, demo de portfólio. Não é cliente: nunca usar como case.
Salva do artifact https://claude.ai/artifact/1vbZPiRTEmHZwGsMbYYaXv em 10/11/2026.

- `index.html` + `img/`: o site (um arquivo só, CSS e JS dentro; só o Lenis por CDN).
- Endereço, horários e preços são de exemplo. Fotos do Unsplash, marcadas como ilustrativas.
- Pedidos do demo vão pro WhatsApp da GuDev.

3 WOWs:
1. **Abertura:** pincelada que revela o pão dentro de um saco de papel kraft, com vapor subindo e selo giratório "assado hoje".
2. **A noite do pão:** a rolagem passa o relógio de 22h a 6h30, o céu amanhece, a brasa do forno acende e a massa crua vira pão assado.
3. **Monte sua cesta:** cartas pra arrastar (direita quero, esquerda passa) e comanda que vai pronta pro WhatsApp.

Extra: painel de fornadas com letras que viram (estilo aeroporto).

Antes de subir: o `index.html` veio com o envelope do artifact (o `<title>` e os `<meta>` ficaram dentro do `<body>`). Funciona, mas o Gu deve arrumar o `<head>`.
