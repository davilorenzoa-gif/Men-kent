# 911 GT3 RS (projeto conceito GuDev)

Demo de portfólio, **não é cliente** (igual Prumo e Peçaí: nunca usar como case).

- `index.html` + `img/`: versão pra subir no Netlify.
- `preview-911.html`: o mesmo site com as imagens embutidas, pra abrir direto no celular.

3 WOWs: o "911" com a foto dentro e o mergulho na haste do 1; o pôster quebrado em 3 cortes que se encaixam;
o launch control (jogo de 0 a 200 km/h com ronco sintetizado e recorde salvo).
Extra: configurador de pintura que muda a cor do carro e do site.

Imagens: pôsteres de referência de ABC.Design e Fins&Fenders, mais uma imagem gerada por IA enviada pelo Davi.
Antes de divulgar publicamente, confirmar se pode usar os pôsteres (são arte de terceiros).
