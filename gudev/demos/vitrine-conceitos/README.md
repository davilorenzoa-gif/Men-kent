# Vitrine de conceitos (demo de técnica)

Estudo do portfólio herasymenkox.com (Yehor Herasymenko), recriado do zero com os conceitos da própria GuDev.
**Todos os projetos são conceitos ou demos. Nenhum é cliente.**

- `index.html` + `img/` (prints das demos tirados com Playwright em 1440x900).
- Precisa de servidor (WebGL não lê imagem por `file://`). Pra abrir no celular, gerar o arquivo único com as fotos em base64 (ver `gudev/03-PADRAO-DE-SITE.md`, bloco do Yehor).
- Arrastar, rolar, setas ou Ant/Próx. Clicar na capa do centro abre o projeto.
- Pra trocar as capas: novos prints em `img/` (16:10), e a lista `PROJ` no script (nome, linha de baixo, link). Máximo de 6 no atlas 3x2.
